Commandes de gestion des salons textuels :
/text create <channel> <category> : Créer un salon textuel dans la catégorie spécifiée.
/text rename <channel> <new_name> : Renommer un salon textuel existant.
/text delete <channel> : Supprimer un salon textuel existant.
/text help [show] : Afficher cette aide (privée par défaut)
Une idée ou un problème ? Utilisez /suggest pour en faire part au staff.
Assurez-vous d'avoir les permissions nécessaires pour utiliser ces commandes.
