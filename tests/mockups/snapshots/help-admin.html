Ce que tu peux lancer ici
Tes rôles Administrateur et Bureau t’ouvrent 38 commandes.
Salons texte
/text create : crée un salon
/text rename : renomme un salon
/text delete : supprime un salon
Salons vocaux
/vocal create : crée un vocal perso
/vocal rename : renomme un vocal
/vocal delete : supprime un vocal
Formations
/fm start : repart d’un nouveau brouillon, qui remplace l’ancien
/fm edit_text : modifie l’intro et la fin
/fm add : ajoute une formation au brouillon
/fm edit : modifie une formation du brouillon
/fm remove : retire une formation
/fm clear : retire toutes les formations
/fm preview : montre l’aperçu du brouillon ici
/fm publish : poste le brouillon dans un salon
/fm export : liste les inscriptions et désinscriptions
Messages du bot
/msg start : commence un brouillon
/msg preview : montre l’aperçu
/msg publish : publie et suit
/msg follow : suit un message envoyé
/msg link_reaction : lie une réaction
/msg unlink_reaction : délie une réaction
/msg list : liste les suivis
/msg export : exporte les réactions
/msg stop : arrête un suivi
/msg clear : efface les derniers messages
/msg purge : efface les messages d’un membre
/msg dm : envoie un MP groupé
Membres et rôles
/user op : donne l’admin temporaire
/user deop : retire l’admin temporaire
/user add_role : donne un rôle
/user remove_role : retire un rôle
/user add_roles : donne un rôle à plusieurs
/user remove_roles : retire un rôle à plusieurs
/user with_roles : qui a ces rôles
Accueil des nouveaux
/welcome verify : allume ou coupe l’accueil
/welcome approve : valide un nouveau
Journaux du bot
/log set : choisit le salon des erreurs
/log export : exporte les journaux
